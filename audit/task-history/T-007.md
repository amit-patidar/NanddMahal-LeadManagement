# T-007: Assignment role correction

Date: 2026-08-20
Status: Done

## Architecture decision

The assignment flow now uses three explicit roles:

- `admin`: manages users, views all leads, and assigns leads.
- `manager`: views all leads and assigns leads, but cannot manage user accounts.
- `sales`: views only leads assigned to that account and cannot assign leads.

The previous **Assign to Me** action is removed from the UI. Admins and managers use an **Assign Lead** user-list dialog or the assignment selector in lead detail. The server rejects sales assignment attempts even if an old client sends an assignment request.

## Implementation

- Added `manager` as a supported CRM role.
- Added manager access to all lead lists, dashboard data, lead detail, WhatsApp access, and the active assignment-user list.
- Kept user creation, activation/deactivation, and password reset admin-only.
- Replaced self-assignment controls with an admin/manager assignment dialog and table/detail selectors.
- Restored assigned-only enforcement for sales users across list, detail, update, and messaging routes.

## Verification

The isolated API suite verifies manager visibility and assignment, manager user-list access without user-management access, admin assignment, sales assigned-only visibility, cross-user URL denial, and blocked sales assignment attempts.
