# T-012: Looking For and Buy Plan column filters

Date: 2026-09-20

## Request

Add separate dropdowns directly inside the Looking For and Buy Plan table headings. The initial Follow-ups and Site Visits scope was extended to every page/tab that displays the shared lead table, including Missed, Upcoming/date views, Rejected, and All Leads. Each dropdown must show that column's unique values rather than adding a separate filter row above the table.

## Implementation

- Enabled header filters in the shared lead table so New Leads, Follow-ups, Site Visits, Super Interested, all three Missed tabs, Rejected Leads, and All Leads behave consistently.
- Built independent, alphabetically sorted option lists from nonblank Looking For and Buy Plan values in the leads loaded for the selected date tab.
- Applied both filters together on the current lead rows without adding an API or database query.
- Reset both selections when the section or Today/Tomorrow/Upcoming/Missed/All view changes.
- Kept the wide table inside its horizontal scroll container on narrow screens.

## Verification

- Browser QA verified unique options, independent and combined filtering, date reset, controls on every lead-list route/tab, and no page-level horizontal overflow at 1440x1000 and 390x844.
