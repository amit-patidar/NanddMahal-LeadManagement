# T-002: Password hashing and migration

Status: Done. Implemented with T-006 on 2026-08-19.

- Passwords use Node `crypto.scrypt` with a random salt and constant-time verification.
- Existing SQLite users were migrated from the legacy password column in a rollback copy and then in the local database.
- The legacy password column is removed after migration; exports/imports use the hash and salt fields.
- Admins can reset a user's password through the Users page.
- Passwords remain in local or Render environment/database storage only and are never committed.

Evidence: `tools/verify-user-access.js`, `audit/task-history/T-006-qa.md`, and the 2026-08 journal entry.
